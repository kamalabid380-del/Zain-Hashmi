# Zain Hashmi — Website

Offline-ready copy of https://www.zainhashmi.com

- 185 pages: home, 29 collections, 144 products, 11 content pages
- All CSS, JavaScript, fonts and 850+ images included

## Run locally

Open `index.html` directly, or start the included server:

- Windows: double-click `Start Zain Hashmi Website.bat` → http://127.0.0.1:3000/
- Or upload the repository to any static host (GitHub Pages, Netlify, Vercel)

Cart, checkout, search and newsletter links still point to the live store.
